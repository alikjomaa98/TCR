# The Common Room

A frontend web app for The Common Room, an independent jazz collective in Beirut. Visitors can browse events, see the services offered, book seats for an event and contact the collective. Built for CSCI426 Advanced Web Programming (Project Phase 1), theme: Event Management System.

## Pages
- **Home**: hero, next session, gallery and call to action
- **Events**: list of upcoming events
- **Services**: live sessions, jam sessions, private events, collaborations
- **About**: who we are
- **Contact**: contact form and details
- **Register** (dynamic): choose an event, enter details and number of tickets. The summary and total update live, bookings are listed and can be cancelled (React `useState`).

## Technologies
React 18, React Router 6, Material UI icons, plain CSS (responsive with media queries).

## Setup
1. Install Node.js
2. `npm install`
3. `npm start` and open http://localhost:3000
